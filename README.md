# myNewTab

一个轻量的 Chrome 本地新标签页扩展。页面保留搜索框、快捷访问和背景图片，使用原生 HTML、CSS、JavaScript 与 Manifest V3 开发，无需安装依赖或构建。

## 功能

- 简洁搜索框：支持 Google、必应和百度，输入网址可直接跳转。
- 搜索建议：即时匹配本地快捷访问，可选开启在线联想，支持方向键选择、回车确认和 Esc 关闭。
- 快捷访问：支持新增、编辑和删除；附带原快捷访问的网站图标，新网站使用 Chrome 的 favicon 接口获取图标。
- 自定义背景：附带背景图和浅色深度的暗色渐变蒙层，支持上传 JPG、PNG、WebP 图片及恢复原图。
- 布局设置：支持居中、靠上和靠下，使用 Flex 布局适配不同窗口宽度。
- 本机保存：快捷访问、背景及设置保存在当前浏览器的本地存储中。

## 安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions`。
2. 开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」（部分版本叫「加载未打包的扩展程序」）。
4. 选择本项目根目录 `myNewTab`，该目录应直接包含 `manifest.json`。
5. 新建标签页；如果 Chrome 询问是否保留新标签页更改，选择保留。

项目当前位置：

```text
C:\Users\admin\Desktop\myproject\myNewTab
```

安装后保留项目文件夹。移动文件夹需要从新位置重新加载扩展。

如果之前加载过「简洁新标签页」，先关闭旧扩展，再加载本项目，避免两个扩展同时接管新标签页。因为目录不同，新扩展的设置不会自动继承旧扩展；原有默认快捷访问及背景已随项目保留。

## 使用

- 输入关键词并回车搜索；输入完整 HTTP / HTTPS 网址直接打开。
- 点击「添加快捷访问」新增网站。
- 悬停快捷访问，点击右上角「⋮」编辑或删除。
- 点击页面右下角铅笔设置搜索引擎、内容位置和背景图片。
- 背景图片最大 3 MB，支持 JPG、PNG、WebP。
- 在线联想默认开启，输入的关键词会发送给当前搜索引擎，可在设置中关闭「在线搜索建议」。关闭后仅显示本地快捷访问匹配和当前关键词搜索入口。
- 联想请求失败时仍可回车搜索；网址类输入不会请求在线建议。

### 隐藏 Chrome 页脚

Chrome 可能在底部显示扩展名称和「自定义 Chrome」。右键点击该灰色页脚，选择「在新标签页页面上隐藏页脚」；也可在 Chrome 的自定义面板中关闭页脚。

这条页脚属于浏览器界面，由 Chrome 设置控制。

## 本地开发

直接编辑源文件即可，没有构建步骤。

修改后在 `chrome://extensions` 中找到 `myNewTab`，点击重新加载按钮，再新建标签页验证。

修改 `defaults.js` 只影响首次使用的默认快捷访问；用户已保存的快捷访问以本机存储为准，请通过页面编辑。

### 普通网页预览

如本机已安装 Python，可在项目根目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8765/newtab.html`。

普通网页预览可检查布局及本地功能，但不具备扩展的 favicon 权限及跨域请求权限。新增网站图标和在线联想应在实际加载的 Chrome 扩展中验证。预览页与扩展的本地存储互相独立，正式使用无需运行服务器。

### 脚本语法检查

如本机已安装 Node.js，可执行：

```powershell
node --check newtab.js
node --check suggestions.js
node --check defaults.js
```

## 权限和数据

- `favicon`：读取网站图标，用于快捷访问。
- 三个搜索建议服务的域名权限：访问 Google、必应和百度的联想接口，仅在开启在线建议时请求当前引擎。
- 在线请求不携带账户凭据，不使用第三方图标查询服务。
- 不申请浏览历史权限，不自动同步或上传快捷访问列表和背景图片。
- 本机设置使用 `localStorage` 保存。卸载扩展可能清除设置，更换目录重新安装也可能产生独立存储。
- 联想接口由对应搜索服务提供，网络状态或接口变更可能影响可用性。

## 编码和维护

所有文本文件使用 UTF-8 无 BOM；中文注释直接使用中文。方法和 CSS 样式应保留中文注释，布局优先使用 Flex，修改尽量保持小范围。

`manifest.json` 使用标准 JSON，不支持注释；其用途在本 README 中说明。

## 恢复默认新标签页

在扩展管理页关闭 `myNewTab`，即可停止由本扩展接管新标签页。

## 分享项目

`defaults.js` 包含当前用户的快捷访问地址，背景图和网站图标也随项目保存。公开发布前，请替换私人链接并确认图片素材的使用授权。
